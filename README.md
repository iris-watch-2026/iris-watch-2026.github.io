# SNS WATCH BOX

SNSの交流候補、手動の巡回・確認、RSS補助、♡記録とフォロー確認を端末内で管理する無料の静的PWAです。

- 公開予定URL: https://iris-watch-2026.github.io/
- HTML/CSS/JavaScript。PHP・ログイン・サーバーDBは使いません。
- 候補とRSS状態はブラウザーのIndexedDB、♡とフォロー分析はブラウザーのlocalStorageに保存します。
- 「保存」→「📦 まとめて保存」で候補・RSS・♡分析を **1つのJSON** に保存。旧URLからは「📂 まとめて復元」で引き継ぎます。個別保存も残しています。
- この公開リポジトリにユーザーデータをアップロードしないでください。
- Xへのいいね・フォローは自動実行しません。RSSは外部サービスに依存し、常に取得できる保証はありません。
- 新URLは旧URLとは別の保存領域です。自動的なデータ移行はありません。手順は MIGRATION.md を参照してください。
- Android PWAインストール、新URLでのRSS通信は未検証です。現在は公開移行の検証段階です。

このリポジトリは公開用コピーです。旧アプリ・旧データは置き換えません。
